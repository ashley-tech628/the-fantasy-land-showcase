# Player guide

The game is a dark fairy-tale adventure combining exploration, clue collection, combat and puzzles. These instructions summarize the final team manual.

## Controls

| Input | Manual-described action |
|---|---|
| W / A / S / D | Move |
| Space | Jump |
| Shift | Accelerate / run |
| Left mouse button | Attack |
| Gamepad A | Accelerate |
| Gamepad B | Jump |
| Gamepad X | Attack |

Some maze sections use F/E/Q and number keys 1/2 to adjust perspective. Controls may vary by scene. The game's help panel documents scene-specific interaction.

## Progression

Explore the library and follow clues, reach Pinocchio's cabin, handle guards and combat, navigate the illusion maze, collect gems for the Queen, and resolve the final arena encounter. Refer to the diary and task panel when the next objective is unclear.

The guide and presentation changed chapter labels across revisions; this summary describes the final documented experience without enforcing a single early storyboard numbering.

## Systems

Open the inventory to inspect or use collected items. Repeated items stack with a quantity indicator. The task panel shows current objectives; later goals are disclosed as earlier stages complete.

The save panel supports saving, loading and clearing progress. Loading returns the scene/player state to the saved snapshot, while clearing begins a new progression state.

This repository contains demonstration media and documentation, not an executable game download.
